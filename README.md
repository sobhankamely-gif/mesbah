# مصباح | حضور و غیاب روزانه

## انتشار روی GitHub Pages
1. یک مخزن **Public** در GitHub بسازید.
2. محتویات این پوشه را در ریشه مخزن بارگذاری کنید؛ نام فایل اصلی باید `index.html` باشد.
3. از مسیر **Settings → Pages**، گزینه **Deploy from a branch** را انتخاب کنید.
4. شاخه `main` و پوشه `/ (root)` را انتخاب و Save کنید.
5. پس از پایان انتشار، لینک نمایش‌داده‌شده در همان صفحه را باز کنید.

## نصب و استفاده آفلاین
- سایت را یک‌بار با اینترنت باز کنید تا فایل‌های اصلی در مرورگر ذخیره شوند.
- سپس از منوی مرورگر گزینه **Install app / Add to Home Screen** را بزنید (در صورت پشتیبانی مرورگر).
- سرویس‌ورکر، پوسته برنامه را برای بازشدن آفلاین نگه می‌دارد. فونت و کتابخانه‌های QR از CDN بارگیری می‌شوند و ممکن است در اولین بار یا هنگام قطع اینترنت در دسترس نباشند.

## نکته مهم درباره اطلاعات
اطلاعات برنامه در حافظه محلی همان مرورگر/دستگاه (localStorage) ذخیره می‌شود؛ با انتشار روی GitHub بین دستگاه‌ها همگام نمی‌شود. از گزینه پشتیبان‌گیری داخل برنامه مرتب فایل پشتیبان بگیرید و آن را در جای امن نگه دارید.
